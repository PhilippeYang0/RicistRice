# RicistRice — dependency manifest
#
# Every program the repo relies on is listed here, next to what uses it, so a
# fresh Ubuntu install can be rebuilt with `scripts/bootstrap.sh` (see the
# "Dependencies" rule in CLAUDE.md). Keep the Stack decisions table in CLAUDE.md
# in sync whenever a stack choice changes.
#
# Sections:
#   [ppa]    add-apt-repository sources, added before [apt] is installed
#   [apt]    one apt package per line, then `# used by: ...`
#   [manual] no clean Ubuntu package — `name :: how to install it`. bootstrap.sh
#            only reports these as found/TODO; `name` must be the command it
#            provides, so it can be detected
#
# Lines starting with # are comments and blank lines are ignored.
# Base-system tools (coreutils, grep, sed, findutils, diffutils, procps) aren't listed.
