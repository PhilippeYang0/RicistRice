# RicistRice — dependency manifest
#
# Every program the repo relies on is listed here, next to what uses it, so a
# fresh Ubuntu install can be rebuilt with `scripts/bootstrap.sh` (see the
# "Dependencies" rule in CLAUDE.md). Keep the Stack decisions table in CLAUDE.md
# in sync whenever a stack choice changes.
#
# Sections:
#   [ppa]    add-apt-repository sources, added before [apt] is installed
#   [apt]    one apt package per line, then `# used by: ...`
#   [manual] no clean Ubuntu package — `name :: how to install it`. bootstrap.sh
#            only reports these as found/TODO. `name` is what it checks for:
#            a command on PATH, `font:<family>` (fc-list), or `path:<file>`
#
# Lines starting with # are comments and blank lines are ignored.
# Base-system tools (coreutils, grep, sed, findutils, diffutils, procps) aren't listed.

# name :: why it's manual, and where to look
awww :: successor to swww, no Ubuntu package — check its upstream repo for the current install method (cargo or release binary) before running anything. Currently installed in /usr/local/bin (awww + awww-daemon). Used by: hypr/hyprland/execs.lua, dotfiles/ricistrice/bin/theme.sh
path:~/.local/lib/ricistrice/qml/Caelestia/qmldir :: caelestia's QML plugin + m3shapes + libcava, not packaged for Ubuntu: run scripts/build-shell.sh (after the [apt] build deps). Used by: dotfiles/quickshell
font:Material Symbols Rounded :: the shell's icon font. mkdir -p ~/.local/share/fonts && curl -L -o ~/.local/share/fonts/MaterialSymbolsRounded.ttf 'https://github.com/google/material-design-icons/raw/master/variablefont/MaterialSymbolsRounded%5BFILL,GRAD,opsz,wght%5D.ttf' && fc-cache
font:Rubik :: the shell's UI font. mkdir -p ~/.local/share/fonts && curl -L -o ~/.local/share/fonts/Rubik.ttf 'https://github.com/google/fonts/raw/main/ofl/rubik/Rubik%5Bwght%5D.ttf' && fc-cache
font:CaskaydiaCove NF :: the shell's monospace font. mkdir -p ~/.local/share/fonts/CaskaydiaCove && curl -L 'https://github.com/ryanoasis/nerd-fonts/releases/latest/download/CascadiaCode.tar.xz' | tar -xJ -C ~/.local/share/fonts/CaskaydiaCove && fc-cache
font:JetBrainsMono NF :: Hyprland group bar font (hypr/hyprland/group.lua). Already installed here; nerd-fonts release JetBrainsMono.tar.xz, same steps as CaskaydiaCove
discord :: .deb from discord.com (no apt repo). Used by: Super+D communication workspace (hypr/utils/functions.lua)
spotify :: Spotify's own apt repo (not a PPA, so bootstrap.sh can't add it): curl -sS https://download.spotify.com/debian/pubkey_5384CE82BA52C83A.asc | sudo gpg --dearmor --yes -o /etc/apt/trusted.gpg.d/spotify.gpg && echo "deb https://repository.spotify.com stable non-free" | sudo tee /etc/apt/sources.list.d/spotify.list && sudo apt-get update && sudo apt-get install spotify-client. Use this .deb, not the snap: SpotX-Bash only patches the snap through a separate script. Used by: Super+M music workspace (hypr/utils/functions.lua)
path:/usr/share/spotify/Apps/xpui.bak :: SpotX-Bash (github.com/SpotX-Official/SpotX-Bash), blocks Spotify ads by patching its files; this backup file means it has been applied. Close Spotify, then: bash <(curl -sSL https://spotx-official.github.io/run.sh). Asks for sudo (the deb lives in /usr/share/spotify). Re-run after every spotify-client upgrade: apt replaces the patched files and ads come back, but this check can't tell (the backup file survives the upgrade)
